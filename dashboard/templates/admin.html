Run state

  

   
Start engine
Native run: launches the bot process if it is not running. In Docker the engine container is always up, so Start wakes it from Pause/Standby instead.

   
Pause (halt)
Stops opening new trades. Open positions keep their stops. The engine stays up and keeps monitoring.

   
Resume
Clears a pause and leaves standby. If the kill switch is armed you must type release.

   
Standby
Pauses trading and idles the engine without exiting. Resume wakes it.

   
Restart
Engine exits cleanly and the supervisor (Docker/systemd) relaunches it. Natively there is no supervisor, so use Stop then Start.

   
Stop
Ends the engine process. Under Docker/systemd it will be relaunched; use Standby there instead.

  

  
Safety

  

   
Kill switch
Immediately stops all trading and LOCKS it: a normal resume is refused until you type release.



   
Mode

There is deliberately no button for LIVE. Going live needs LIVE_TRADING=true in .env and a restart, so a stray click can never risk real money.

   
Demo test trade
Places ONE minimum-size (0.01 lot) gold buy on the MT5 demo account through the normal order path, so you can watch it appear in the trade log and close at its stop or target. Only works in demo mode.

   
Dry test
Checks connections, candle data and strategy decisions for every market. Places no orders.
